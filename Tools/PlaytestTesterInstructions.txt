GUARDS OF ATLANTIS II - DIGITAL PROTOTYPE
PRIVATE PLAYTEST INSTRUCTIONS FOR INVITED TESTERS

Thank you for testing. This is a private, unfinished prototype. Please read all of
this once before we start - especially the section headed PLEASE READ THIS ONE.
The whole session takes roughly two hours.


PLEASE READ THIS ONE: WHO YOU ARE TRUSTING

One machine hosts this match. It holds every card in the game and decides every
rule; all six of us are clients of it. Whoever runs that machine can read anything
in the match, including the cards in your hand, and could change what the game
does. Nothing in this build prevents that, and nothing is meant to. The session key
you are given is an invitation that keeps strangers out and scrambles the traffic on
the way; it is not protection from your host. (The game will not host a match over
the internet without a key at all - but a key only settles who else can listen in,
never what the host itself can see.)

This is fine here because six people who know each other are testing a prototype
together. It is not a competitive service, there are no accounts, and there is no
anti-cheat. Please do not play on a host you do not trust.

The build is yours to run and not yours to pass on. Please do not upload it, share
it, mirror it or post a link to it anywhere. Delete it when we are finished.


WHAT YOU NEED

  - A Windows 10 or 11 PC.
  - The zip you were sent, unpacked to a folder you can write to.
  - Four things sent to you privately, never in this file:
        the host ADDRESS       (looks like 203.0.113.10)
        the host PORT          (a number, often 45677)
        the SESSION KEY        (a long random string; treat it like a password)
        YOUR SEAT              (one of red-player-01, red-player-02, red-player-03,
                                blue-player-01, blue-player-02, blue-player-03)

Everyone must run the exact copy of the build that was sent - this is the newest
one, and it does not talk to any older copy. A different build is refused the
instant you try to join; that is deliberate, not a bug, so there is no way to
accidentally mix an old copy into this session.


1. STARTING THE GAME

Double-clicking the executable itself starts a local practice mode with no lobby
in it. That is not what we want. Two launcher files sit next to it; use one of
those instead:

    PLAY - Join Match.bat      the one you want. It starts the game with the
                               lobby and writes your log file for you, named
                               playtest-<your Windows username>.log.
    HOST - Start Server.bat    only for whoever is hosting the match. You can
                               ignore it.

(Wondering about practicing alone first? You can play a full six-seat match by
yourself: run HOST - Start Server.bat, then also run PLAY - Join Match.bat on the
same PC, point it at 127.0.0.1 and the same key, pick whichever seat you want to
play, and press JOIN then READY as normal. Now switch back to the HOST window and
press its FILL WITH TEST DRIVERS button - it fills every other still-open seat
with a QA test driver, not a real opponent, just random legal moves at a watchable
pace, clearly labeled as a test driver only on the host's own screen. Each one
dials the same address the host is actually using and either joins for real or
gives up loudly - if a seat cannot be filled, the host's own screen says so by
name instead of the practice game quietly hanging. The match begins itself once
all six seats are ready, exactly as in a real session, so you get to play your one
seat and watch the other five play themselves. It plays no part in the six-person
session itself - nobody presses FILL once real people are joining.)

The first time, Windows may say "Windows protected your PC". Choose "More info",
then "Run anyway" - the build is unsigned, which is expected for a private
prototype.

If you would rather start it by hand, open the folder, hold Shift and right-click
in it, choose "Open in Terminal" or "Open PowerShell window here", then paste one
line:

    .\GuardsDigitalSmoke.exe -guardsPrivateLobby -logFile playtest-YOURNAME.log

Replace YOURNAME with your own name, in lowercase and with no spaces. That second
flag writes the log file next to the game; we need it afterwards.

A window headed PRIVATE LOBBY should appear. If it does not, tell us before doing
anything else.


2. JOINING THE MATCH

  1. Type the ADDRESS you were sent into the ADDRESS box, replacing 127.0.0.1.
  2. Type the PORT into the PORT box.
  3. Paste the SESSION KEY into the SESSION KEY box. It must match exactly.
  4. Find YOUR SEAT in the table and press PICK on that row. The line above the
     table should then read SEAT: <your seat>. Please take only the seat you were
     given; two people racing for one seat just wastes a join.
  5. Press JOIN.

You should see your row change to SEATED with YOU beside it, and the other seats
fill in as everyone arrives.

If something refuses you, the lobby says why in one line. The common ones:

    "That seat is already taken."        Someone took your seat. Tell us; do not
                                         quietly take a different one.
    "The session key did not match."     Re-paste the key; watch for a trailing
                                         space.
    "The host could not be reached."     The host is not running yet, or the
                                         address or port is wrong.
    "The host is running a different
     build."                             You have the wrong copy of the game.

Once every seat says SEATED, press READY. The match starts by itself the moment all
six seats are ready - nobody presses a start button. The lobby then disappears and
the board takes over.


3. PLAYING

Play the game normally and take as long as you like over your turns; nothing is on
a timer, and a long match is fine - a bug that used to silently freeze the whole
table partway through a long game is now fixed, so play on for as many rounds as
the match takes. A few things are worth knowing:

  - You can only see your own hand. That is the point of the test.
  - When your team has to agree on something - which of two tied heroes goes first,
    or which minion is removed - everyone on that team has to say the same thing
    before it happens. You can change your mind; changing it un-agrees everyone and
    the team states it again. There is no captain and no automatic tiebreak.
  - When someone levels up at the end of a round, END TURN is on screen the whole
    time it is your turn, right from the start, even in the middle of choosing a
    target or a destination. One press does two things at once: it drops whatever
    you had not yet actually committed to, and it hands your turn on. Undo is for
    taking back something you truly did; END TURN is only for ending your turn -
    they are not the same button doing the same job twice, and pressing END TURN
    is instant and final the moment you press it, so do not press it by reflex if
    you are not sure you are done. If END TURN looks dim rather than gold, hover
    over it and it will say why - usually because a printed rule says this step
    cannot be skipped, or because someone else's decision is what the game is
    actually waiting on right now, not yours.
  - There is an UNDO button: the square with the curved arrow, just to the left of
    END TURN at the top. While your own cards are resolving it steps your turn
    back one action at a time, as far as the moment your turn began. It will not
    undo an attack - once you have chosen a target, the defender has already
    answered and that cannot be unseen - so it stops just after an attack rather
    than going through it. It only ever moves your own turn, only you can press
    it, and everyone else simply sees the board step back with you.
  - Watch the top bar. The whole strip across the top of the screen turns gold
    whenever the game is waiting on you specifically - your turn, a decision only
    you can make, or simply choosing which card to commit at the start of a round.
    If it is not gold, it is not waiting on you.
  - Blocked actions grey out instead of being offered and then doing nothing. If a
    card or option looks dim, it is not available right now and clicking it will
    not spend it. Hover over any greyed control and it will name the reason -
    another hero's card already standing in the way, nothing left worth targeting,
    or whatever else is actually stopping it - rather than leaving you to guess.
  - Your own cards and hand shine gold too: a card glows when it is the answer the
    game is waiting on you to give, and while one of your cards is resolving it
    keeps glowing while the rest of your hand dims, so your eye stays on the card
    that is actually doing something. That glow, the top bar, and the ring around
    a hero's own piece on the board all breathe with a slow circling light while
    you are the one being waited on - it is meant to catch your eye without being
    urgent about it. In earlier builds that circling light never actually appeared
    on a tray or a card, however gold they went; it does now.
  - That gold means one thing only: this is yours to answer. It is worth saying
    because it used to leak - your own committed card kept glowing while somebody
    else was taking their turn. If you see anything of yours glowing gold while
    the game is plainly waiting on another player, that is worth reporting.
  - Every hero's tray lights up while THAT player is the one being waited on, not
    just yours - levelling up, answering a defence, choosing where a defeated hero
    comes back, or simply taking their turn. So you can see who the table is
    waiting for without asking.
  - There is a record of the match now. The narration bar at the top has a small
    chevron; click the bar or the chevron and a scrollable list drops down -
    moves, attacks, defences, skills, defeats, end-of-round results, and who took
    back what. Click the chevron again, or anywhere else on the screen, to close
    it. It will not cover anything you are being asked to answer.
  - The buttons have been rebuilt. Every named button on screen now shares one
    look and one feel, and dips slightly when you press it. This includes the
    HOST, JOIN, FILL and PICK buttons on the lobby screen, which until now had no
    styling at all. Nothing about what they do has changed - only how they look
    and respond - so please say if any of them now feels wrong to press, or if
    one you expect to be clickable no longer looks like it is.
  - A narration bar names who is acting and what they are deciding, and a gold ring
    marks that hero's own piece on the board - so it is easy to see whose turn it
    is and what they are doing even from across the table.
  - The board itself now shows you what is happening instead of just jumping
    between still pictures. A piece that moves slides along the path it actually
    took rather than teleporting. An attacker leans into whatever it strikes -
    another hero's piece or one of the small enemy figures, it plays the same way
    for both now. The struck piece visibly registers the hit, a returning piece
    pops back in, and a defeated piece now shrinks and fades away where it stood
    instead of vanishing between one frame and the next. If you played the last
    build: the floating attack and defence numbers have been REMOVED on purpose,
    because they did not work well enough to keep. Their absence is not a fault -
    a different way of showing an attack is being designed.
  - Playing Arien, Tigerclaw, Sabina or Brogan? A card that says "you may" - "you
    may move 1 space", "you may retrieve", "you may discard" - used to offer you a
    CONFIRM button that the rules then refused, so the only answer that worked was
    DECLINE. Ten cards across those four heroes were affected. Now CONFIRM appears
    only when there is genuinely something to confirm, and DECLINE is the one
    answer for "no thanks". Please try one of those cards both ways.
  - Levelling up at the end of a round now happens for everyone who earned a level
    at the same time, each on their own screen, instead of the table waiting while
    each of you is asked in turn. Answer your own upgrade choice whenever you are
    ready; the round moves on once the last person who levelled has answered, so
    if you levelled up, do not wait to be asked - your prompt is already there.
  - Playing Brogan? A charge card now moves him to the picked destination the
    instant you pick it, and only then asks who the attack targets - from his new
    square, not his old one. Once that attack resolves it is committed like any
    other attack: it cannot be undone back through, same as every attack above.
  - The interface is deliberately plain. It is being tested for whether it is
    understandable, not for whether it is pretty. If something is confusing, say
    so - that is data.

Please tell us, out loud or in chat, whenever anything looks wrong, stops
responding, disagrees with what someone else is seeing, or takes an oddly long time.
We are writing all of it down and none of it is a complaint.


4. IF YOU GET DISCONNECTED

Nothing is lost and nobody is replaced. Your seat is held for you and the whole
match stops where it stands until you are back, so the other five will be sitting
and waiting.

If the game window is still open, the lobby reappears over the board with two
buttons:

    RECONNECT   goes back into your own seat and picks up exactly where you were.
                Use this one.
    LEAVE       deliberately gives up your seat. Once you press it, anyone holding
                the session key can claim your seat - do not press it unless you
                mean to stop playing.

Press RECONNECT. If it fails, or the game itself has closed or crashed, just start
it again the normal way - same launcher, same address, port, key and seat you were
given the first time - and rejoin. You do not need to do anything special: your
seat is reserved and you are dropped straight back into it, with everything as you
left it.

If your machine is out of action for the rest of the evening, tell us. The host can
free your seat from their own console with a typed "release <your seat>" once it
shows as disconnected, without restarting the match for everyone else - but that
only works on a seat that has actually dropped; it is not a way to remove someone
who is still playing. Once released, the seat goes back to Open and anyone holding
the session key could claim it, so this is genuinely for "I am out for the night,"
not a pause.

If the host machine itself goes away, every client says HOST LOST and that match is
over - it cannot be continued or restored. We would start a new one.

Please do not close the game window to fix a problem unless we ask you to.


KNOWN PROBLEMS IN THIS BUILD

These are already known. Please do not spend time writing them up in detail - a
short note that you saw one is enough - but do say so, because it might be a
different problem wearing the same coat.

Five of the six problems listed here for the last build are fixed in this one -
the missing match record, the silent failed card, the glows that lit only for the
player being asked, Arien's Living Tsunami CONFIRM button, and the defeated piece
that vanished instead of fading. If you saw any of those before, they should be
gone; say so if they are not.

  - When a card's effect stops partway through, the game now says so and waits for
    you to acknowledge it - but it names only the card that stopped, not what
    stopped it. So you will be told THAT something was blocked and which card it
    was, and not yet WHY. Naming the blocker needs a change deeper in the rules
    engine than this build carries. If you can work out what blocked it, that is
    genuinely useful to us.
  - If one part of the screen ever freezes or goes blank while everything else on
    screen keeps working, that is a single panel failing on its own rather than the
    whole game going down - it should not take your turn with it. Play on if you
    can, and tell us; the log file next to the exe will help us find it.


5. AFTER THE MATCH

Two things, please:

  1. Send back the log file the game wrote - playtest-<name>.log, in the same
     folder as the executable; the launcher names it after your Windows username.
     Send it privately, the same way you received the build.
     It contains only your own seat, version numbers and the public result. It does

Thank you. This is the first time this game has been played by six people over the
internet, and the only way to find out what is wrong with it is to have you play it.
