## Current implementation

The project has completed roadmap milestones through **8.8b**. The configured vertical slice uses a pure match application service, typed action handlers, authoritative projections, deterministic replay/Undo, map-bound snapshots, and passive Unity presentation; schema v22 persists every continuation the slice can pause on, together with every hero's progression, every team's counters, and the board's own components. It plays rulebook p.7's turn inside p.8's round: cards commit and reveal under Initiative, a turn spends one action or Holds, an Attack runs p.13's whole consequence list, the round closes through p.8's six ordered steps, and the match ends by one derived outcome naming winner, loser and cause. It is dealt from verified content: both mirrored seats hold Wasp's printed cards, and a printed primary whose text has no composition yet is offered greyed and refused rather than performed without it. A player sees all of it on one runtime UI Toolkit panel. The exact inventory of implemented behavior, configured setup, compatibility boundaries and gaps lives in [Project/CURRENT_IMPLEMENTATION.md](Project/CURRENT_IMPLEMENTATION.md) and the shards the routing table below names; every statement this summary compresses is stated once by the shard that owns it.

Accounts, public matchmaking, public distribution, and production live-service scope remain excluded.
