# Player colours and shared map signals

Canonical presentation and communication contract for milestone 9.81. Return to [match HUD](MATCH_HUD.md) or [experimental features](EXPERIMENTAL_FEATURES.md#implemented-communication-contract).

**9.81 player identity amendment:** the existing hero token outline and tray portrait outline, tinted panels and border lines use a stable per-player accent within each team palette. This supersedes the acting hero's separate gold-ring treatment: its outline emits a repeating player-coloured outward ripple, with faint ripples for its other bodies. Allied hovered hexes ripple inward; persistent pings ripple outward and split their six edges among senders. The host alone adjusts ripple speed and intensity in the existing Director drawer. See [communication contract](EXPERIMENTAL_FEATURES.md#implemented-communication-contract); gameplay legality, active-effect cues and timer votes remain separate.

**9.81 player signals:** wire 47 carries team-filtered hovered hexes and presentation-only ripple settings. Stable seat-owner ordering assigns red-side orange/yellow/magenta and blue-side cyan/green/violet. Existing token outlines and tray portrait/background/border styling use that identity without new tray decoration. Acting-token outlines emit outward ripples; teammate cursors contract inward and persistent pings expand outward. Multiple pingers divide the six hex edges in stable sender order, without moving portraits. Timer votes retain their existing separate presentation.

Cursor input is bounded to the selected map, coalesced to at most ten host publications per second, and does not change ping revisions, gameplay history/version or command acknowledgement. Pointer exit/focus loss/disable clears it; departure and restart clear the corresponding host signals. The host's Director drawer sets the session-wide ripple period (400–4000 ms, default 1400 ms) and intensity (0–100%, default 100%); zero intensity suppresses the wave, not the steady outlines. Settings reach reconnecting clients even when coordination is off and never change gameplay clocks or snapshots. Remote seats have neither a settings command nor authority through hidden Director controls.
